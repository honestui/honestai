Every sample below is a fixed chat reply rendered by the same code that renders a model's reply in `GenerativeChat`. Open **Code** to see the Markdown and `honestai` block the model writes. No model is called. Figures are sample data unless a sample says otherwise; the planet table uses rounded real values.

Buttons, follow-ups and form submits show what they would send instead of starting a conversation. To see a model choose these components itself, open the [playground](/docs/generative/playground). [Reply features](/docs/generative/replies) explains the controls on tables, charts, artifacts and visuals.
