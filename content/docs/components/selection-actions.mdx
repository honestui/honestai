## Overview

Selection Actions is a small bar of edits for selected text: Improve, Shorten, or an instruction the person types. While the edit runs it shows progress. When the edit returns, it asks the person to keep or discard it.

The bar is the controls only. Tracking the selection, placing the bar near it, making the edit, and showing the rewritten text are your application's work. You tell the bar where things stand through `status`.

## Behavior

### Status

- `idle` shows the actions and the prompt field.
- `working` shows a shimmering label and no controls.
- `result` shows Keep and Discard.
- `error` shows a message and Discard.

Pass `onRetry` to add Try again to a result or an error.

### Prompt

Pass `onPrompt` to add the field. Send is disabled while it is empty, and the field clears after sending.

## Accessibility

The bar is a toolbar with a name. Working and the error are announced through a status that stays mounted. The prompt field has a name, and Send is a submit button.

When the status changes, the buttons under focus are replaced. Move focus to the new controls from your handler if the person triggered the change from the keyboard.

With reduced motion, the working label does not shimmer.

| Key | Action |
| --- | --- |
| <kbd>Tab</kbd> | Move across the actions, the prompt field, and the decision buttons |
| <kbd>Enter</kbd> | Send the typed instruction, or activate the focused button |

## Usage

```tsx
import { SelectionActions } from "@/components/ai/selection-actions"

<SelectionActions
  status={edit.status}
  actions={[
    { id: "improve", label: "Improve" },
    { id: "shorten", label: "Shorten" },
  ]}
  onAction={(actionId) => edit.run(actionId, selection.text)}
  onPrompt={(instruction) => edit.runCustom(instruction, selection.text)}
  onKeep={edit.accept}
  onDiscard={edit.reject}
  onRetry={edit.retry}
/>
```

## API reference

### SelectionActions

Accepts native div props beyond those listed.

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `actions` | `SelectionAction[]` | Required | Each has `id`, `label`, and an optional `icon`. |
| `status` | `"idle" \| "working" \| "result" \| "error"` | `"idle"` | Where the edit stands. |
| `onAction` | `(actionId: string) => void` | Required | Runs when an action is pressed. |
| `onPrompt` | `(instruction: string) => void` | None | Passing it adds the prompt field. |
| `onKeep` | `() => void` | Required | Accepts the result. |
| `onDiscard` | `() => void` | Required | Rejects the result, or dismisses an error. |
| `onRetry` | `() => void` | None | Passing it adds Try again. |
| `labels` | `Partial<SelectionActionsLabels>` | English | The toolbar name, field names, status messages, and button names. |
