## Overview

Fine-tune Card is a small panel of controls for adjusting a result without writing another prompt: a chart's size, a reply's length, a tone. You describe the controls as data, and the card reports every value when one changes.

The card holds the values and nothing else. Regenerating or restyling the result is your application's work, in `onValuesChange`.

## Behavior

### Numbers

A number field accepts typing, steps with the arrow keys, and scrubs when its label is dragged sideways. `min`, `max`, and `step` are enforced by the field.

### Edited and Reset

When any value differs from `defaultValues`, the header says Edited and offers Reset, which returns every control to its default and reports the defaults through `onValuesChange`.

## Accessibility

The card is a group named by its title. Its controls are the Honest UI [Number Field](https://www.honestui.com/docs/components/number-field), [Toggle](https://www.honestui.com/docs/components/toggle) group, and [Select](https://www.honestui.com/docs/components/select), each named by its label, and they keep their own keyboard behavior. Scrubbing is an extra for pointer users. Every value can also be typed.

Edited is a polite status, so it is announced when the first change is made.

| Key | Action |
| --- | --- |
| <kbd>Tab</kbd> | Move across the controls |
| <kbd>↑</kbd> and <kbd>↓</kbd> | Step a number field |
| <kbd>Enter</kbd> or <kbd>Space</kbd> | Choose a segment, or open the menu |

## Usage

```tsx
import { FineTuneCard } from "@/components/ai/fine-tune-card"

<FineTuneCard
  title="Reply style"
  defaultValues={{ length: 300, tone: "neutral" }}
  controls={[
    { type: "number", id: "length", label: "Max words", min: 50, max: 1000, step: 50 },
    {
      type: "select",
      id: "tone",
      label: "Tone",
      options: [
        { value: "neutral", label: "Neutral" },
        { value: "formal", label: "Formal" },
      ],
    },
  ]}
  onValuesChange={(values) => reply.regenerate(values)}
/>
```

`onValuesChange` runs on every change, including each step of a scrub. Debounce it if your handler starts a request.

## API reference

### FineTuneCard

Accepts native div props beyond those listed.

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `title` | string | Required | What is being adjusted. |
| `controls` | `FineTuneControl[]` | Required | The controls, in order. |
| `defaultValues` | `FineTuneValues` | Required | The starting value for every control `id`. |
| `onValuesChange` | `(values: FineTuneValues) => void` | None | Runs with every value when one changes. |
| `labels` | `Partial<FineTuneCardLabels>` | English | The Edited note and the Reset name. |

### Types

| Export | Shape |
| --- | --- |
| `FineTuneControl` | `type` of `"number"` (with optional `min`, `max`, `step`), `"segment"`, or `"select"` (each with `options`), plus `id` and `label` |
| `FineTuneValues` | A number or string for each control `id` |
