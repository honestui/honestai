## Overview

Search List is a search field over one flat list. Typing filters the list, the arrow keys move through it, and choosing an item calls `onSelect`.

It is the Honest UI [Command](https://www.honestui.com/docs/components/command), arranged for this one case. Use Command directly when you need groups, shortcuts, or a dialog.

## Behavior

### Filtering

Items are matched against their `label`, ignoring case. The description is shown but not searched.

### Empty

When nothing matches, `emptyMessage` replaces the list. Say how to recover, such as clearing the search.

## Accessibility

Search List takes its keyboard and screen reader behavior from Command: the field is a combobox, focus stays in it, and the highlighted item is exposed to assistive technology. Pass `label` to name the field. A placeholder is not a name.

| Key | Action |
| --- | --- |
| <kbd>↓</kbd> and <kbd>↑</kbd> | Move through the items |
| <kbd>Enter</kbd> | Choose the highlighted item |

## Usage

```tsx
import { SearchList } from "@/components/ai/search-list"

<SearchList
  label="Search saved prompts"
  placeholder="Search saved prompts…"
  items={prompts.map((prompt) => ({ id: prompt.id, label: prompt.title }))}
  onSelect={(item) => composer.insert(item.id)}
/>
```

## API reference

### SearchList

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `items` | `SearchListItem[]` | Required | Each has `id`, `label`, and optional `description`, `icon`. |
| `onSelect` | `(item: SearchListItem) => void` | Required | Runs when an item is chosen. |
| `label` | string | Required | Names the search field. |
| `placeholder` | string | None | Shown while the field is empty. |
| `emptyMessage` | string | English | Shown when nothing matches. |
| `className` | string | None | Added to the root. |
