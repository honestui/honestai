## Overview

Filter Table puts a row of chips above a table. Each chip is one filter and shows how many rows it matches. Pressing a chip shows only those rows.

The counts are computed from the rows you pass, so a chip never disagrees with the table under it.

Use [Data Table](https://www.honestui.com/docs/product/data-table) when people also need search, sorting, selection, or pagination.

## Behavior

### Filters

One filter is active at a time. All shows every row. A filter is a function, `matches`, so it can test anything on the row.

### Empty

A chip that matches no rows shows 0 and can still be pressed. The table then shows `emptyMessage` in place of the rows.

## Accessibility

The chips are a named group of toggle buttons, and the active one reports that it is pressed. The table uses native table markup with column headers, and is named by `label`.

When the filter changes, a polite status announces how many rows are shown, as "2 of 5".

| Key | Action |
| --- | --- |
| <kbd>Tab</kbd> | Move across the chips |
| <kbd>Enter</kbd> or <kbd>Space</kbd> | Apply the focused filter |

## Usage

```tsx
import { FilterTable } from "@/components/ai/filter-table"

<FilterTable
  label="Agent tasks"
  rows={tasks}
  getRowId={(task) => task.id}
  columns={[
    { id: "title", header: "Task", cell: (task) => task.title },
    { id: "owner", header: "Owner", cell: (task) => task.owner },
  ]}
  filters={[
    { id: "open", label: "Open", matches: (task) => !task.isDone },
    { id: "done", label: "Completed", matches: (task) => task.isDone },
  ]}
/>
```

## API reference

### FilterTable

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `label` | string | Required | Names the table. |
| `columns` | `FilterTableColumn<Row>[]` | Required | Each has `id`, `header`, and `cell`. |
| `rows` | `Row[]` | Required | The rows to show and count. |
| `getRowId` | `(row: Row) => string` | Required | A stable id for each row. |
| `filters` | `FilterTableFilter<Row>[]` | Required | Each has `id`, `label`, and `matches`. |
| `allLabel` | string | `"All"` | The chip that shows every row. |
| `filtersLabel` | string | English | The group name read before the chips. |
| `emptyMessage` | string | English | Shown when the filter matches no rows. |
| `activeFilter` | `string \| null` | None | The active filter's `id`, when you control it. |
| `defaultActiveFilter` | `string \| null` | `null` | The initially active filter. |
| `onActiveFilterChange` | `(filterId: string \| null) => void` | None | Runs when a chip is pressed. |
