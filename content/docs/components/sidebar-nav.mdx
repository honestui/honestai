## Overview

Sidebar Nav is the side navigation of a chat product. It has a short list of destinations, a New chat button, and the person's past conversations with a search field over them. It collapses to a rail of icons.

It renders the items and threads you pass and reports what was pressed. Routing and loading conversations are your application's work.

## Behavior

### Collapsing

Collapsed, the nav keeps the collapse button and the destination icons. The header, the chat list, and the footer are left out, because the rail has no room for their text. Control it with `collapsed` and `onCollapsedChange`, or let it manage itself.

### Searching chats

Typing filters the chats by title. When nothing matches, the list is replaced by a message that names the search. With no chats at all, the search field is left out and the list says so.

## Accessibility

The component is a navigation landmark with a name. Every row is a button. The current destination is marked with `aria-current="page"`, and the open conversation with `aria-current`.

The collapse button reports whether the nav is expanded. Collapsed, each destination keeps its label as its accessible name. The empty and no-match messages are statuses. With reduced motion, the width changes at once.

| Key | Action |
| --- | --- |
| <kbd>Tab</kbd> | Move across the rows and the search field |
| <kbd>Enter</kbd> or <kbd>Space</kbd> | Open the focused destination or chat, or collapse the nav |

## Usage

```tsx
import { SidebarNav } from "@/components/ai/sidebar-nav"

<SidebarNav
  header={<WorkspaceName />}
  items={[
    { id: "home", label: "Home", icon: <HomeIcon /> },
    { id: "files", label: "Files", icon: <FileIcon /> },
  ]}
  activeItemId={route.section}
  onNavigate={(itemId) => router.push(`/${itemId}`)}
  threads={chats}
  activeThreadId={route.chatId}
  onThreadSelect={(threadId) => router.push(`/chat/${threadId}`)}
  onNewChat={() => router.push("/chat/new")}
/>
```

The nav fills its parent's height, so place it in a full-height layout.

## API reference

### SidebarNav

Accepts native nav props beyond those listed.

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `items` | `SidebarNavItem[]` | Required | Each has `id`, `label`, `icon`, and an optional `badge`. |
| `activeItemId` | string | None | The item for the current page. |
| `onNavigate` | `(itemId: string) => void` | Required | Runs when a destination is pressed. |
| `threads` | `SidebarNavThread[]` | Required | Each has `id` and `title`. |
| `activeThreadId` | string | None | The open conversation. |
| `onThreadSelect` | `(threadId: string) => void` | Required | Runs when a chat is pressed. |
| `onNewChat` | `() => void` | None | Passing it adds the New chat button. |
| `header` | ReactNode | None | Shown at the top while expanded. |
| `footer` | ReactNode | None | Shown at the bottom while expanded. |
| `collapsed` | boolean | None | The collapsed state, when you control it. |
| `defaultCollapsed` | boolean | `false` | The initial collapsed state. |
| `onCollapsedChange` | `(collapsed: boolean) => void` | None | Runs when the collapse button is pressed. |
| `labels` | `Partial<SidebarNavLabels>` | English | Landmark, button, and field names, and the empty messages. |
