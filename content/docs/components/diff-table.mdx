## Overview

Diff Table shows edits an agent proposes to a table, one row for each addition and removal, with unchanged rows for context. Every change starts selected. The person clears the ones they do not want and applies the rest.

`onApply` receives the ids of the changes that stayed selected. Making the edits is your application's work.

Use [Change Review](https://www.honestui.com/docs/product/change-review) for field-by-field changes to one object.

## Behavior

### Selecting changes

A selected addition is tinted green and a selected removal is tinted red with its cells struck through. Clearing a change removes the tint, and the row is left as it is today. The footer counts what is selected, and Apply is disabled when nothing is.

### Applying

If `onApply` returns a promise, Apply shows progress and the checkboxes lock until it settles. When it resolves, the footer confirms how many changes were applied. When it rejects, the footer shows an error and keeps the selection.

## Accessibility

The table uses native markup with column headers and is named by its title. Each changed row has a real checkbox, named for what it does, such as "Include removing fax_number". The word Add or Remove is in the row, so the tint is never the only cue.

The footer's count is a polite status, so it is announced as the selection changes. The error is an alert.

| Key | Action |
| --- | --- |
| <kbd>Tab</kbd> | Move across the checkboxes and Apply |
| <kbd>Space</kbd> | Select or clear the focused change |
| <kbd>Enter</kbd> or <kbd>Space</kbd> | Apply |

## Usage

```tsx
import { DiffTable } from "@/components/ai/diff-table"

<DiffTable
  title="Proposed changes to the customers table"
  columns={[
    { id: "column", header: "Column" },
    { id: "type", header: "Type" },
  ]}
  rows={proposal.rows}
  onApply={(rowIds) => agent.applyEdits(proposal.id, rowIds)}
/>
```

## API reference

### DiffTable

Accepts native div props beyond those listed.

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `title` | string | Required | What the edit is. |
| `columns` | `DiffTableColumn[]` | Required | Each has `id` and `header`. |
| `rows` | `DiffTableRow[]` | Required | Changed and unchanged rows, in order. |
| `onApply` | `(includedRowIds: string[]) => void \| Promise<void>` | Required | Receives the selected changes. |
| `labels` | `Partial<DiffTableLabels>` | English | Column name, change words, checkbox names, and footer messages. |

### Types

| Export | Shape |
| --- | --- |
| `DiffTableRow` | `id`, `change` of `"unchanged"`, `"added"`, or `"removed"`, `name`, and `cells` keyed by column `id` |
