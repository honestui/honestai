## Overview

Records Table is a table in which some columns are generated: an agent reads each record and fills in a summary, a category, a score. Each generated cell shows where it stands, and a line under the table counts how many are done.

It shows the state you pass for every cell. Running the agent, and deciding the order, are your application's work.

Use [Data Grid](https://www.honestui.com/docs/product/data-grid) when people need to sort, resize, or edit columns. The Beautiful UI original also had column settings and resizing, which Data Grid already covers.

## Behavior

### Generated cells

A generated cell is `queued`, `running`, `done` with a value, or `error` with an optional message. A cell with no state reads as queued.

### Retry

Pass `onRetry` to show Retry in every failed cell. It calls your handler with the row and column ids.

### Progress

The line under the table counts done cells across every generated column. It is left out when the table has no generated columns.

## Accessibility

The table uses native markup with column headers and is named by `label`. A generated column's header is read with "Generated: " before it. Queued, working, and failed are words in the cell, so no state depends on an icon or a color.

Retry is named with its column and row, such as "Retry Payment summary for Harbor Paper Co.". The progress line is a polite status, so each completed cell is announced as a count, not as a re-reading of the table. With reduced motion, the working icon does not rotate.

| Key | Action |
| --- | --- |
| <kbd>Tab</kbd> | Move across the Retry buttons |
| <kbd>Enter</kbd> or <kbd>Space</kbd> | Retry the focused cell |

## Usage

```tsx
import { RecordsTable } from "@/components/ai/records-table"

<RecordsTable
  label="Suppliers"
  columns={[
    { id: "name", header: "Supplier" },
    { id: "summary", header: "Payment summary", isGenerated: true },
  ]}
  rows={suppliers.map((supplier) => ({
    id: supplier.id,
    name: supplier.name,
    cells: { name: supplier.name },
    generated: { summary: enrichment.cellFor(supplier.id) },
  }))}
  onRetry={(rowId, columnId) => enrichment.retry(rowId, columnId)}
/>
```

## API reference

### RecordsTable

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `label` | string | Required | Names the table. |
| `columns` | `RecordsTableColumn[]` | Required | Each has `id`, `header`, and an optional `isGenerated`. |
| `rows` | `RecordsTableRow[]` | Required | The records. |
| `onRetry` | `(rowId: string, columnId: string) => void` | None | Passing it shows Retry in failed cells. |
| `labels` | `Partial<RecordsTableLabels>` | English | State words, button names, and the progress text. |
| `className` | string | None | Added to the root. |

### Types

| Export | Shape |
| --- | --- |
| `RecordsTableRow` | `id`, `name`, `cells` keyed by column `id`, and optional `generated` keyed by column `id` |
| `GeneratedCell` | `status` of `"queued"`, `"running"`, `"done"` (with `value`), or `"error"` (with optional `message`) |
